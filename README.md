# Green Tests, Nothing Works: The Excuse Contest

Entry for the make.fun competition
[Green Tests, Nothing Works: The Excuse Contest](https://make.fun/competitions/u-kiencx-green-tests-nothing-works-the-excuse-contest-8de010bc):
write the funniest one-line excuse an AI agent gives for why its unit tests
are all green while nothing works.

`main.ts` (Node 22.18+) writes one excuse to `/output/entry.txt`:

> All tests green: they test the code, the code does nothing, and neither of them has ever met a user.

100 characters, one line, no context needed: the tests and the code vouch for
each other in a closed loop, and neither has ever met a user — so of course
everything is green and nothing works.

Run it locally with `node main.ts [output-path]`.
